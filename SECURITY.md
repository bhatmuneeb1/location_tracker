# Security Policy

## Reporting

Please report vulnerabilities privately to the maintainer before public disclosure. Include the affected commit/version, reproduction steps, impact, and any suggested fix.

Do not include real third-party credentials, private databases, or personal data in a report.

## Privacy expectations

This project is intended to perform lookups against a local MaxMind database. A change that silently transmits queried IP addresses or lookup results to a remote service would violate the project's privacy model and should be treated as a security issue.
